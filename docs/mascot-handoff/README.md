# Mascot designer and player handoff

Start with [HANDOFF_PROMPT.md](HANDOFF_PROMPT.md). It specifies a native Solid designer, a state-machine player lab, and integration with existing agent-session signals.

[mascot-handoff.zip](mascot-handoff.zip) contains the reusable source, current authored character and matching sprite sheet, reference designer, working Canvas 2D state-machine lab, tests, contracts, and verification notes. Extract it to a temporary working directory and follow its README. No package install is required to run the reference.

This directory is the migration handoff. The production application has not yet been wired to the mascot.
